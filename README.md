## 🎯 О проекте
Данный проект представляет собой интерактивную веб-систему для фиксации и анализа когнитивных автоматизмов в реальном времени. Система разработана по принципу **Privacy-by-Design** — сбор данных происходит полностью анонимно без сбора персональных данных пользователей.

Проект спроектирован как полноценный источник генерации уникальных датасетов для последующего статистического анализа.

🔗 **Живая демо-версия в интернете:** [https://onrender.com](https://onrender.com)

## 🛠️ Технологический стек (Stack)
* **Backend:** Python, FastAPI, Uvicorn
* **Database & ORM:** SQLite, SQLAlchemy ORM
* **Frontend:** HTML5, CSS3 (Анимированные градиенты, Glassmorphism UI), JavaScript (Async Fetch API)
* **DevOps & Cloud:** Git, GitHub, Render Cloud Platform

---

## 📊 Архитектура и функционал
1. **Сбор точек присутствия (UX):** Интерактивная форма фиксации мыслей с защитой от перезагрузки страниц и мгновенным обновлением счетчиков без обновления экрана.
2. **Анонимная идентификация:** Сквозное отслеживание уникальных пользователей с помощью генерации беспарольных сессий через `UUID` и безопасные `HTTP-only Cookie`.
3. **Панель аналитика данных (Admin Dashboard):** Встроенный интерфейс общего мониторинга метрик, активности пользователей и почасового распределения логов.
4. **Data Export:** Функция мгновенного экспорта накопленного массива данных в чистый формат `.csv` (разделитель `;`) для последующего импорта в Excel или Python Pandas.
